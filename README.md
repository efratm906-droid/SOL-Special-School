# SOL-Special-School

Project Description:
SQL project on information management for a special education school.
The project includes database design, creating tables and relationships between them,and using SQL queries for information management and retrieval.

Project Objective:
The project objective is to design and build a database for a special education school,
applying principles of database design, creating relationships between tables, and retrieving information using SQL queries.
